# P23 Marketing Engine

Forked from `sales-engine` at commit `1116d2c3d378143805a44545c947606ff9075faa`.

## Overview
P23 Marketing Engine is the marketing client for lead capture, multi-channel source attribution, intelligent duplicate detection, interest tagging, lead scoring, and automated sales rep round-robin assignment.

- **Phase 1**: Frontend-only demo running entirely on Mock Service Worker (MSW) in the browser with realistic dummy data.
- **Phase 2**: Full backend integration connecting to `sales-engine/backend` services.

## Development
```bash
npm install
npm run dev
```

Run tests:
```bash
npm test
```
